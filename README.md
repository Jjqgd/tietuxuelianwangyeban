# 铁途学练 · 电脑网页版（GitHub Pages 部署版）

面向职工的铁路工务刷题系统，纯前端单页应用，放在 GitHub Pages 上即可用浏览器打开，支持电脑宽屏、平板、手机三种尺寸。
授权方式未变：**一机一码（设备码 + 激活码）**，旧激活码继续有效。

---

## 一、目录说明

| 文件 / 文件夹 | 作用 | 是否必须 |
| --- | --- | --- |
| `index.html` | 主程序（页面、逻辑、授权校验全在这一个文件里） | 必须 |
| `import.html` | 导入题库的辅助页 | 必须 |
| `manifest.json` | 应用清单（打包 / 添加到桌面用） | 可选 |

| `html2pdf.bundle.min.js` | 导出 PDF（带水印）用 | 必须 |

> 仓库建议设为 Public（免费版 Pages 只支持公开仓库）。公开仓库意味着 `index.html` 的源码对外可见，所以防盗靠的是下文第三部分的机制，而不是"藏代码"。

## 二、第一次部署（网页上传，不用装任何软件）

1. 打开 <https://github.com>，注册或登录账号。
2. 右上角 `+` → **New repository**，仓库名填 `tietu-web`（可自定，英文小写），选 **Public**，点 **Create repository**。
3. 进入仓库后点 **Add file → Upload files**，把本文件夹里**所有文件**（连同 `404.html`、`.nojekyll`）拖进去，底部点 **Commit changes**。
   - 注意：`.nojekyll` 是隐藏文件，Windows 资源管理器里需要先开启"显示隐藏文件"；如果拖不进去，可用 **Add file → Create new file**，文件名填 `.nojekyll`，内容留空，直接提交。
4. 仓库页 **Settings → Pages**：`Build and deployment` 的 `Source` 选 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`，点 **Save**。
5. 等 1～3 分钟，刷新 Settings → Pages 页面，顶部会出现网址：
   `https://你的用户名.github.io/tietu-web/`
   打开这个网址就是正式版。
6. 首次打开会进入授权页，把页面上的**设备码**发给客服换激活码，输入后即可使用（流程和以前完全一样）。

## 三、以后更新版本

只改了一个文件时：仓库页 → **Add file → Upload files** → 拖入新的 `index.html` → **Commit changes**，1 分钟左右线上自动生效（浏览器按 `Ctrl+F5` 强制刷新可立刻看到新版）。

改多个文件时：同样的上传方式，一次拖入全部即可，同名文件会自动覆盖。

> 建议每次大改动前，把整个文件夹另存一份带日期的备份（例如 `铁途学练-网页版-20261125`）。

## 四、这一版做了什么（电脑适配 + 防盗升级）

**电脑网页版适配**
- 宽度体系：手机保持 480px 原样；平板 720px；桌面首页 1200px、答题页 860px，不再出现"手机版被拉宽"的空白。
- 首页改为桌面双栏看板：左边训练区，右边题库与提示区；工具按钮改为三列大按钮。
- 练习 / 背题 / 考试页：题面按阅读宽度排版，按钮和选项加大，悬停有反馈。
- 键盘操作：`A`~`D` 或 `1`~`4` 选答案、`Enter` 下一题、`←`/`→` 切题、`Esc` 关闭答题卡。
- 弹窗、抽屉、搜索框在桌面端改为居中大面板；答题工具条吸顶，滚动时始终可点。

**防盗升级（授权方式不变）**
1. 校验密钥不再以明文出现在源码里，改为运行时由打散的密文还原 —— 直接搜索源码搜不到密钥。
2. 站点锁：只允许在 GitHub Pages 域名（`*.github.io`）、`localhost` 和自己填的白名单域名运行；被别人复制到其他网站打开会直接提示"当前站点未授权"。
3. 反嵌套：被其他网页用 iframe 嵌进去使用时拒绝授权。
4. 授权记录与站点绑定：把浏览器存储复制到别的域名也无效。
5. 激活尝试限流：每小时最多 10 次，防止暴力试码。
6. 题面加"专属编号"水印（很淡，不影响阅读），截图外传可追溯到设备码。
7. 内容保护：题面、选项、解析禁止选中复制；浏览器 `Ctrl+P` 打印被拦截（导出请用软件内的导出功能）。
8. 导出 PDF、复制题目文本、分享卡片，全部自动带上"专属编号 + 日期"水印。

> 老实说明：纯前端 + 公开仓库的方案，只能"大幅提高破解和二次分发的门槛"，做不到绝对防破解。真要彻底防，需要授权服务器（激活码由服务器签发与校验）。现在这版是所有静态托管方案里性价比最高的做法。

## 五、你可能要改的几处配置（都在 `index.html` 里，搜索关键字即可）

| 搜索关键字 | 默认值 | 说明 |
| --- | --- | --- |
| `AUTH_HOSTS` | `['github.io','xiaogezi.top','localhost','127.0.0.1']` | 发布域名白名单。绑定了自己的域名（如 `tietu.xxx.com`）要加进去，否则会提示"当前站点未授权"。 |
| `AUTH_ALLOW_FILE` | `true` | 是否允许本地双击 `index.html` 打开。正式上线后可改为 `false`，本地预览版就打不开了（更严）。 |
| `AUTH_TRIAL_MS` | `2 * 24 * 60 * 60 * 1000` | 免费体验时长，默认 2 天。 |
| `AUTH_TRY_LIMIT` | `10` | 每小时允许的激活尝试次数。 |
| 价格表 | `2 / 4 / 7 / 18 / 30 / 49.9 / 99.9` | 授权页的价格卡片，按需改数字。 |

## 六、签发激活码（重要：此工具不要上传到仓库）

激活码仍由本地签发工具生成（`铁途核验` 文件夹里的 `gen-code.js`），算法没变：
输入用户发来的设备码 → 生成激活码 → 发给用户。

**安全要求**：签发工具包含真正的校验密钥，只能留在自己电脑上，**绝对不要上传到 GitHub、不要发给客户**。仓库里只有程序本体，不含任何签发能力。

## 七、常见问题

**打开是白屏 / 一直转圈**
按 `Ctrl+F5` 强制刷新；仍不行则检查 `font.ttf`、`xlsx.full.min.js`、`html2pdf.bundle.min.js`、`qrcode.min.js`、`logo.png` 是否都上传成功（缺一个就会卡住）。

**提示"当前站点未授权"**
说明访问的域名不在 `AUTH_HOSTS` 里。GitHub Pages 默认域名已通配；如果用了自定义域名，把域名加进 `AUTH_HOSTS` 重新上传即可。

**提示"网络未连接"**
授权校验需要联网取标准时间。连上网后点"重新联网校验"即可，做题进度不会丢失。

**换电脑 / 换浏览器要重新激活吗？**
要。授权是绑设备 + 绑浏览器的：换浏览器、清空浏览器数据、用无痕模式，都会被视为新设备，需要用新设备码重新换码（这是防盗设计的一部分）。

**手机能打开吗？**
能。同一网址在手机浏览器里就是手机版布局，和原来一致；也可以"添加到主屏幕"当 App 用。

**导出 PDF 乱码 / 排版错**
导出用的是浏览器端渲染，建议用 Chrome 或 Edge，缩放保持 100%。
